3 · Code reviewer

Review exact proposals

The reviewer can approve or request changes. Their signed review names the proposal checkpoint. Reviewing never changes the parent.

4 · CI

Check exact proposals

CI checks changed files for empty contents and unresolved conflict markers, then signs a pass or fail for the proposal checkpoint.

5 · Integrator

Accept approved changes

Only the integrator action writes the parent. It requires signed reviewer approval and passing CI, then checks whether the changed paths still fit.
