# Public memos

PARAM separates finite Projects, ongoing Areas, reusable Resources, retained Archives, and operating Memos. Apply only categories that help the work; intent, guidance and runbooks describe how this repository operates.

- [Projects](projects/README.md): current finite outcomes and next actions.
- [Areas](areas/README.md): ongoing source maintenance.
- [Resources](resources/README.md): reusable reference material.
- [Archives](archives/README.md): inactive public records.
- [Repository guidance](guidance/repository.md): placement, authority and verification.

Public plans are maintained here as they are adopted. Private planning and article drafts remain in Drive. This initial scaffold does not migrate the Drive workspace or duplicate its full planning history.
